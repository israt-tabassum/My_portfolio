Research Output

A Hybrid Deep Learning Approach for Multi-Class Cyberbullying Classification Using Multi-Modal Social Media Data

This paper addresses the urgent need for efficient systems to identify and classify cyberbullying across multiple classes using multi-modal social media data. It explores the application of transformer-based deep learning models, such as RoBERTa for text and Vision Transformer (ViT) for images, to enhance classification accuracy.

A Deep-Learning Based Approach for Multi-Class Cyberbullying Classification for Text and Image Data

This study employs a deep-learning approach using two datasets: one self-collected and another public to identify cyberbullying. It trains nine deep-learning models, including ResNet-50, CNN, and ViT for image data, and LSTM-2, GRU, RoBERTa, BERT, DistilBERT, and a hybrid CNN+LSTM model for textual data, demonstrating the effectiveness of these models in classifying cyberbullying.

Multi-Class Classification of Air Quality from Image Data

This work develops a deep learning-based framework for multi-class classification of air quality from image data. It employs both traditional deep learning models (CNN and ResNet-50) and transformer architectures (ViT and Swin transformer), alongside traditional machine learning classifiers like SVM and Random Forest, to enhance performance and broaden the methodological landscape for environmental monitoring.

Fake News Detection: Covid-19 Perspective

This study collects a new dataset for detecting fake news from traditional media on Covid-19, comprising over 3,000 news pieces, with 170 identified as fake from fact-checking sites. It tests four existing classification algorithms using Count Vectorizer and TF-IDF, analyzing the outcomes to assess the effectiveness of these methods in identifying fake news.

Bar 2-Visibility Representations of 2-Planar Graphs

This paper introduces an algorithm to efficiently calculate bar 2-visibility representations for embedded 2-planar graphs with face length five and a maximum of 5n−10 edges, where n represents the size of the graph. This representation ensures that each edge intersects no more than two bars, contributing to the understanding of graph drawing structures.
