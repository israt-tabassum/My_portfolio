# Israt Tabassum — Portfolio

Static portfolio site built with [Astro](https://astro.build).

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
npm run preview  # serve the built site
```

## Editing content

All text — bio, publications, experience, projects, education, skills — lives in
`src/data/profile.ts`. Edit it and rebuild; no HTML changes needed.

## Security

- Fully static output: no server, database, forms or secrets.
- Zero client-side JavaScript; fonts are self-hosted (no third-party requests).
- Strict Content-Security-Policy generated by Astro (`security.csp` in `astro.config.mjs`).
- `public/_headers` adds HSTS, `X-Frame-Options`, etc. on Netlify / Cloudflare Pages.
- External links use `rel="noopener noreferrer"`.

## Deploy

**Coolify (live at https://israt.no):** the app uses the Dockerfile build pack with base
directory `/website_update` and port `80`. The `Dockerfile` builds the site and serves
`dist/` with nginx (`nginx.conf` sets the security headers). Push to `main`, then redeploy
in Coolify (or enable auto-deploy).

**Other hosts / custom domain:** run `npm run build` (optionally with `SITE_URL=https://your.domain`)
and deploy `dist/` to Netlify, Cloudflare Pages or Vercel. `public/_headers` applies
there; GitHub Pages ignores it.
